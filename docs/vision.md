# Vision

Annoda is a free decentralized dating protocol for verified adults, licensed under GNU AGPLv3 or any later version. Independent peers own identity keys, distribute public profiles and photographs, and compute personal recommendations locally. Volunteer nodes provide optional storage and relay capacity. No proprietary mandatory service, advertisements, subscriptions, internal chat, or private photo messaging.

Recipients see received likes before reciprocation. A match requires two authenticated positive intents. External contacts require separate explicit consent after matching. There is no global popularity or Elo score. CIE is authoritative for real identity and adulthood; an authorized issuer remains a cryptographic trust anchor. See [identity](identity.md).

First milestone: executable local Rust network with synthetic adults and generated images, replicated photos, offline encrypted delivery, matching, explicit contacts, private ranking, and a small binding surface. Real CIE, production model inference, Internet NAT traversal, and mobile applications are future adapters. Availability depends on participating nodes; global erasure of public content is impossible. Production launch requires the operational work in [security](security.md).
